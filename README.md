One line, from the machine's own mouth: a smug self-checkout machine flags a basket of twelve yogurts and nothing else as a cry for help — and still charges for the bag.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
